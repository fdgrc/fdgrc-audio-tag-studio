# GitHub web upload — V1.6.5

This release is intentionally safe for the GitHub browser uploader.

The changes-only ZIP contains no directory names with `[` or `]`. Extract the ZIP, then drag its contents into GitHub's **Add file → Upload files** page. Do not upload the ZIP itself.

You do not need to delete older `[model]` or `[...path]` folders already in the repository for V1.6.5 to work. They are no longer called by the app.
